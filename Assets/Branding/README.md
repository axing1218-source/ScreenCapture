# StarCap Logo Assets

Official StarCap branding source for v0.9.7.

- Project: StarCap
- Author: 阿星
- Canonical source: `starcap-logo.svg`
- Mark: five-point star with five color-separated points
- Background: transparent for production assets

## Canonical source

`starcap-logo.svg` is the authoritative logo master in this repository. The transparent separators between the five colored star segments are part of the approved design.

Official colors:

- Blue: `#0081FD`
- Red: `#F93132`
- Green: `#18B44F`
- Orange: `#FE7201`
- Yellow: `#FEBD02`

Do not recreate production icons from historical raster files. The previously committed `starcap-logo-256.png`, `starcap-logo-master-1024.png`, and `starcap.ico` were corrupted and have been removed.

## Windows application icon

The application/taskbar/Explorer icon is generated by:

`tools/generate_starcap_icon.ps1`

Production resource:

`Src/Res/logo.ico`

## Windows tray icon

The notification-area icon is generated separately by:

`tools/generate_starcap_tray_icon.ps1`

Production resource:

`Src/Res/tray.ico`

The approved tray variant keeps the exact StarCap logo geometry and only enlarges the complete mark for small-icon rendering:

- 16 px: 128%
- 20 px: 126%
- 24 px: 124%
- 32 px: 118%
- 40 px: 112%
- 48 px: 110%
- 64 px: 108%

The tray-specific scaling must not be used to alter the normal application/taskbar/Explorer logo.
