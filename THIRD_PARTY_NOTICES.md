# Third-party notices

## ClipboardManager

WeShot v0.9.1's clipboard-manager prototype intentionally adapts interaction and visual ideas from the public open-source project **ZiuChen/ClipboardManager**:

- Repository: `https://github.com/ZiuChen/ClipboardManager`
- License: Apache License 2.0

The WeShot implementation is a native Win32/C++ rewrite rather than a copy of the Vue/JavaScript runtime. Its tabs, list-card presentation, search behavior, favorites, duplicate promotion, full-view concept, keyboard workflow, and 800-item/14-day defaults are deliberately kept close to the public project for evaluation before WeShot-specific refinement.

The Apache License 2.0 license text for the upstream project is available in that repository's `LICENSE` file.
