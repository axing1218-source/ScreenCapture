# Third-Party License Copies

This directory collects license texts for third-party open-source components that are bundled with or linked into StarCap builds.

- `cgif-MIT.txt` — cgif GIF encoder
- `Ling-MIT.txt` — Ling GUI framework
- `Yoga-MIT.txt` — Yoga layout engine used by Ling
